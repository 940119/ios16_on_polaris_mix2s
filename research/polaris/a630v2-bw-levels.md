# MiCode Polaris v2 GPU/GMU HFI 带宽档位

[Polaris MP v2 顶层 DTS](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/arch/arm64/boot/dts/qcom/polaris-mp-v2.dts#L15-L26) 和 [P0 v2](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/arch/arm64/boot/dts/qcom/polaris-p0-v2.dts#L15-L26) 都包含 `sdm845-v2.dtsi`。该 [GPU 覆盖](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/arch/arm64/boot/dts/qcom/sdm845-v2.dtsi#L550-L649) 的 `qcom,chipid=0x06030001`，初始 pwrlevel=6（257MHz，DDR case4），而不是基础 `sdm845-gpu.dtsi` 的初始级别5；频点由快到慢 `710/675/596/520/414/342/257/0 MHz`，对应 bus case `12/12/10/9/8/6/4/0`。尤其 342MHz 的 v2 case **6** 不是基本 DTS 同位置的 case5。GMU v2 频点为 `0/200/500 MHz`。

[GPU DDR](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/arch/arm64/boot/dts/qcom/sdm845-gpu.dtsi#L92-L113) 路径 `26→512` 13 case 的 `IB(KBps)` 顺序是 `0,400000,600000,800000,1200000,1648000,2188000,2724000,3072000,4068000,5184000,6220000,7216000`；[GMU CNOC](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/arch/arm64/boot/dts/qcom/sdm845-gpu.dtsi#L299-L315) 路径 `26→10036` 2 case 是 `0,100`。[`kgsl_hfi.h`](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/drivers/gpu/msm/kgsl_hfi.h#L154-L162) 限定 GX levels 16、CNOC levels 2、DDR 每 case 最多 8 条、CNOC 最多 6 条命令。[`hfi_send_bwtbl`](https://github.com/MiCode/Xiaomi_Kernel_OpenSource/blob/polaris-o-oss/drivers/gpu/msm/kgsl_hfi.c#L400-L449) 从厂商 bus query 的结果填充 HFI 表，**并非从上述 KBps 数值直接计算 TCS 数据**。

`tools/polaris_bw_levels.py` 和其单元测试用严格匹配确认 v2 chipid、级别、13+2 路径和 HFI 数量形状，拒绝 v1 索引或查询结果超容量；并不获取任何真实 RSC 指令。最后仍须证明 XNU 资源归属并取得可信 `msm_bus_scale_query_tcs_cmd_all` 等价结果。当前 CPU framebuffer 继续默认；不进行 GPU/GMU MMIO、CI 完整构建或手机启动/刷写。
